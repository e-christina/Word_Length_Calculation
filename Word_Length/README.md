This repository contains python scripts created with AI (Gemini and ChatGPT) that compute word length for both syllables and letters.

The "Corpus_Preprocessing" folder contains scripts that mainly lemmatize, deduplicate, remove non-english words and split content and all words (functions and content words).

The "Final_Calculation_of_Word_Length_for_All_Corpora" folder contains scripts that process the final output from the "Corpus_Preprocessing" files. 

Academic Vocabulary List (Gardner & Davies, 2014) reqiured no preprcessing apart from coverting it to '.txt'. 
It is available here: https://www.academicvocabulary.info/download.asp

## Reference 
Gardner, D., & Davies, M. (2014). A New Academic Vocabulary List. Applied Linguistics, 35(3), 305–327. https://doi.org/10.1093/applin/amt015
