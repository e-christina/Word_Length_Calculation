These two scripts calculate word length for all corpora; for all word lemmas (content and function) and content word lemmas.

## Prerequisite
Before running these two scripts, 
1) first run the scripts in the "Corpus_Preporpcessing" folder.
2) and move the output files to the current folder here.

## Requirements

Both scripts require the following libraries:

```bash
pip install nltk g2p_en
```
